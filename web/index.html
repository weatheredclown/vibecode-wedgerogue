Controls

  • Arrow Keys — Fly the ship (press P to toggle Alt/Classic mode).
  • Space — Shoot.
  • M — Drop a mine (after unlocking the upgrade).
  • T — Teleport (after unlocking the upgrade).
  • Enter / Space — Advance through dialog and menus.
  • 1, 2, 3 — Pick dialog or shop choices.

The JavaScript port currently focuses on the core combat loop. The store, options menu, music system, and starmap sequences are still being recreated. Look for TODO comments in the source if you would like to help finish the port!
